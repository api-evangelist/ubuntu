Multiple vulnerabilities discovered in libheif affecting Ubuntu 20.04 through 26.04. Issues include denial of service from malformed HEIF sequences, infinite loops, arbitrary code execution from crafted HEIF/AVIF files, mask image handling flaws, grid-based file information disclosure, overlay compositing issues, and sequence file parsing failures.
